# Self Management V3.3 — Time Tracking

Draft branch. `main` remains the stable V3.2 Goals frontend until the V3.3 Apps Script backend is deployed.

V3.3 adds:
- a Time Log with permanent TL IDs
- Estimated Hours on actions
- action-completion time capture
- manual time logging against actions, projects, goals, or general work
- rollups by action/project/goal
- a Time view with weekly/monthly/all-time totals and recent entries
- Goal and Project time summaries
- edit/delete for time entries

The master Google Sheet schema has already been migrated. Publish the frontend only after the V3.3 backend has been deployed and smoke-tested.
